# Changelog

## 0.1.0 - 2026-11-15

First public-quality release of the extraction tool.

- PDF inspection, text and image extraction, and vector-region rendering.
- Parsers for the Sportbootführerschein See and Binnen layouts, including navigation tasks.
- Validation findings, JSON schema 1.0, and CSV export.
- Guarded download of the two catalog URLs verified on 2026-11-15.
- Tests use synthetic PDFs. Optional integration tests run only when the official PDFs are present locally.
